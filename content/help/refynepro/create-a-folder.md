Folders keep related documents together. You can create a folder at the top level of your
workspace, or inside an existing folder to build a nested structure.

## Steps

1. In the Document Tree, right-click an empty area. To put the new folder *inside* an existing
   folder, right-click that folder instead.
2. Choose **New Folder**.

   ![The New Folder option in the Document Tree right-click menu](2026-08-09-14-26-08.png)

3. Type a name in the box that appears, then press **Enter**.

Your folder appears in the Document Tree and a **Folder created** message confirms it.

**Other ways to do this:** open a folder in the Workspace and click **New Folder** in the
toolbar above the list.

![The New Folder button above the folder contents in the Workspace](2026-08-09-14-32-32.png)

> **Tip:** Press **Esc** while typing to cancel. Leaving the name empty cancels too.
